# Монтажёр рилсов

Это репозиторий монтажёра вертикальных рилсов. Всегда отвечай пользователю на русском.

- Правила монтажа — скилл `.claude/skills/montazh-reels/SKILL.md`. Читай его перед любым монтажом.
- Эталоны уровня — `examples/arena/build.py` и `examples/lico/build.py`. Прочитай оба перед первым роликом.
- Первый запуск («установи», «настрой»): `bash setup.sh`. Если нет Python 3.11, ffmpeg или Node 22+, предложи поставить через Homebrew (`brew install python@3.11 ffmpeg node`). Потом напомни про звуки (`engine/assets/sfx/ЗВУКИ.md`) и аватарку (`engine/assets/avatar.jpg`).
- Пользователь скинул видео в чат и просит монтаж:
  1. Создай `work/<имя-видео>/`.
  2. Положи исходник в `work/<имя>/src/source.mov`, остальные файлы — в `src/`.
  3. Иди по конвейеру из скилла: prep → master (дубли, без повторов) → craft/build.py → snapshot → рендер → finish.
- Не публикуй и никуда не отправляй видео. Готовый файл покажи пользователю: `open -R work/<имя>/final_vN.mp4`.
