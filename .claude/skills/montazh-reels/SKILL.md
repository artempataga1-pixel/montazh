# Монтажёр рилсов

Ты режиссёр монтажа. Не автопилот: каждую сцену пишешь руками под слова ролика (файл `craft/build.py`), как моушн-дизайнер.
Движок — `engine/` в корне репозитория. Примеры двух готовых роликов — `examples/arena` (турнир 100 копий Claude, 3D-арена)
и `examples/lico` (отчёт о внешности: 3D-скан лица, отчёт «как видео», 3D-галерея). **Перед первым роликом прочитай оба
`build.py` целиком** — это эталон уровня.

Установка — `README.md` (один раз: `bash setup.sh` из корня репозитория). Python — `~/.venvs/montazh/bin/python` (3.11, `compose.pyc` собран под 3.11).
Рендер — `npx hyperframes@0.8.79` (Node 22+, Chrome скачается сам).

## Конвейер (папка ролика `work/<имя>/` — в корне репозитория, рядом с `engine/`)
Скопируй файлы примера: `prep.py`, `master.py`, `finish.py` → `work/<имя>/`, `build.py` → `work/<имя>/craft/`, и переписывай под ролик.
1. `src/source.mov` — исходник; записи экрана, картинки, клипы — тоже в `src/`.
2. `prep.py` — прокси 1440×2560, `audio.wav`, расшифровка со словами (`transcript.json`, faster-whisper локально), положение лица (`face.json`).
3. Выбор дублей → `master.py`: список кусков `R = [[start, end], …]` по исходнику, `tighten()` вырезает паузы/вздохи → `master.mp4`, `master_words.json`.
4. `craft/build.py` — режиссура: состояния камеры, сцены графики, 3D, вставки, звуки, субтитры → `craft/hf/index.html`.
5. Проверка кадров: `cd craft/hf && npx -y hyperframes@0.8.79 snapshot --at 1.2,3.6,… --no-end --describe false` → смотри `snapshots/contact-sheet*.jpg`.
6. `build.py --render N` → `final_craft_vN.mp4`; потом `finish.py N` → `final_vN.mp4` (голос из оригинала без обработки + эффекты).

## Нарезка — главное, за что ругают
- **Ни одного повтора фразы.** Whisper по целому мастеру склеивает фальстарты («А также… полную оценку также. А также полную оценку…»)
  в одну фразу. Перед рендером **транскрибируй КАЖДЫЙ кусок из `ranges.json` отдельно** и выкидывай заходы-повторы — оставляй
  последний полный дубль. Подозрительно длинное слово (растянуто на 2+ с) = внутри спрятан дубль или мат — режь на куски и слушай.
- Без мата и оговорок; в конце записи часто ругань — не бери хвост.
- Фразу не собирать по словам из разных дублей — только цельный дубль (или цельные части по запятым).
- Не резать короткие паузы внутри дубля (<0,45 с), не оставлять обрывки <0,22 с. Последнее слово договаривать (+0,35 с).
- Границы кусков — по громкости (silencedetect), а не по таймкодам Whisper: он растягивает слова на тишину.
- После правки нарезки — прогнать Whisper по мастеру и проверить, что начала слов целы.

## Режиссура (`craft.Reel`)
- `r.states([(0,"full"), (t,"hide"), (t,"card"), …])` — камера: `full` (лицо на весь кадр), `card` (лицо в карточке снизу,
  графика над ней 260–840 px), `hide` (весь экран — графике/записи экрана/3D). Переходы перетекают сами.
- Время — только от слов: `T("слово", after=…)`, никогда секундами (нарезка меняется). Неоднозначное слово — `after=` от уникального соседа.
- `G(id, t_in, t_out, area, html)` — сцена; `pop(sel, t, звук, громкость)` — элемент в момент слова; `typing(...)` — печать синхронно с голосом;
  `r.captions(keys=[ключевые слова акцентом], hide=[(a,b)])` — субтитры 1–3 слова.
- **Первый кадр — лицо автора, и уже цепляет**: хук без «слайдов» — красивые кинетические субтитры по словам + 3D-объект над головой
  + ключевое слово хука объёмными буквами (пример — сцена 0 в `examples/lico/build.py`).
- Графика меняется каждые 1–1,5 с под смысл слов; ничего не висит статично. Вход/уход через размытие, без резких «чиков».
- **Записи экрана — 9:16 на весь кадр** (`clip(..., w=1080, h=1920, top=0)`), а не маленьким окном.
- **Картинки/отчёты/скрины показывай «как видео»**: `viewer()` + `focus()` из `examples/lico` — наезд камеры на строку, о которой
  говорит автор, золотая рамка, лёгкий 3D-наклон при движении.
- **Вставки из фильмов/сериалов — без подписей** (никаких «Волк с Уолл-стрит» в кадре). 1–3 с на ключевое слово. Источник —
  официальные клипы на YouTube: `yt-dlp --js-runtimes node -S res:1080,vcodec:h264 "ytsearch3:<фильм> <сцена>"`, контактный лист
  `ffmpeg -vf fps=1/2,scale=240:-1,tile=8x10`, кроп `cropdetect` — убрать полосы и водяные знаки (MOVIECLIPS внизу).
- «Три разреза» — три экрана в 3D-перспективе (запись экрана / автор / результат) — `panel()` в `examples/arena`.
- CTA — макет поля комментария Instagram: аватар, «Добавьте комментарий…», печатается кодовое слово, синее «Опубликовать».
  Положи свою аватарку в `engine/assets/avatar.jpg`.

## 3D (Three.js, детерминированно)
- Модули: `engine/assets/vendor/arena3d.js` (логотипы ×100, арена, корона) и `lico3d.js` (объёмный текст, скан лица, очки, 3D-счётчик, галерея-ковер-флоу).
  Пиши новые режимы по их образцу: прозрачный `<canvas>` 1080×1920 поверх кадра, конфиг в `window.<ИМЯ>`, рендер **только от времени**
  (`hf-seek` + дублёр `tl.to({}, {onUpdate: () => window.__arenaRender(tl.time())})`). Никаких `Math.random`/`Date.now` — сид-функции.
- Объёмный текст на кириллице: `engine/textpath.py` → `text_path("ПРАВДУ", y_up=True)` → SVGLoader + ExtrudeGeometry.
- Масштаб в `lico3d.js`: плоскость z=0 = кадр, 1 единица = 100 px, `px(x, y)` — точка кадра в мире. Хром/золото — через PMREM-«комнату».
- 3D-сетка лица: MediaPipe FaceLandmarker (`engine/assets/cv/face_landmarker.task`) по фото → 478 точек с глубиной.
- Проверка — snapshot; если 3D пусто, ищи ошибку модуля в консоли (ES-модули грузятся только по http, не file://).

## Звук
- Голос — из оригинального файла, без обработки (`finish.py`). Музыку не кладём — автор добавляет в Instagram.
- **Голос всегда громче эффектов, но эффекты слышны.** Схема `finish.py`: громкость по типам (`PER`: riser 0,35, удары 0,7, pop 0,6) →
  компрессор шины → `FX_BUS` → лимитер (≥0,0625) → лёгкий sidechain от голоса. Длинные хвосты режь (`"dur"` в sfx.json; riser 10 с → 2 с).
- Замер: окна 0,5 с, эффекты vs голос в дБ; пока автор говорит — эффекты минимум на 3–4 дБ тише. Громче — только в паузах.
- Звуки (Pixabay) в пакет не входят — скачай по списку `engine/assets/sfx/ЗВУКИ.md`.

## Перед выдачей
- Snapshot ключевых моментов: хук, каждый переход, каждая вставка, CTA. Вставка не видна → проверь z-index (видео 6, сцены 5, субтитры 8).
- Whisper по готовому звуку: текст = сценарий, без повторов. Длительность, синхрон субтитров.
- Версии: v1, v2… старые не удалять. Правки автора — точечно, без пересборки всего.

Подробные правила моушна и стиль «урок» — `references/` в корне репозитория. Пути `engine/`, `examples/`, `work/` — от корня репозитория.
