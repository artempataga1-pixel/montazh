# Монтажёр рилсов для Claude Code

Записал видео, скинул в Claude Code и получил рилс уровня топовых AI-блогеров:
- **Нарезка без мусора.** Лучшие дубли, без повторов, пауз и оговорок.
- **Моушн-графика под каждую фразу.**
- **3D.** Объёмный текст, 3D-иконки и 3D-сцены на Three.js.
- **Вставки из фильмов и сериалов** по смыслу, без подписей.
- **Субтитры и цепляющий хук.**
- **Поле комментария Instagram** с кодовым словом в конце.
- **Звук.** Голос всегда громче эффектов.

Всё работает локально, без платных API. Монтирует сам Claude прямо в чате. Пошаговая инструкция с картинками — [ИНСТРУКЦИЯ.pdf](ИНСТРУКЦИЯ.pdf).

## Быстрый старт
1. Скачай репозиторий. Открой Claude Code в пустой папке и напиши:
   `Склонируй сюда https://github.com/artempataga1-pixel/montazh`
   Или на GitHub нажми Code → Download ZIP.
2. Открой в Claude Code папку `montazh` и напиши:
   `Установи монтажёра: запусти setup.sh и поставь всё, чего не хватает`
3. Скачай звуки по списку `engine/assets/sfx/ЗВУКИ.md` и положи свою аватарку в `engine/assets/avatar.jpg`.
4. Запиши рилс, перетащи видео в чат и напиши:

```
Смонтируй рилс из этого видео. Возьми лучшие дубли, вырежи повторы, паузы и оговорки.
Сделай красиво, в стиле топовых блогеров:
— крутую моушн-графику и моушн-дизайн под каждую фразу;
— 3D-анимации: 3D-иконки, 3D-текст ключевых слов, 3D-сцены;
— реальные вставки из фильмов и сериалов по смыслу, без подписей;
— красивые субтитры, в начале — хук, который цепляет с первого кадра.
В конце — поле комментария Instagram, печатается слово АГЕНТ.
Голос всегда громче звуковых эффектов.
```

Через 15–30 минут получишь `work/<имя>/final_v1.mp4`. Правки пиши обычными словами («звуки тише», «на 12-й секунде повтор»), и Claude соберёт v2.

Папку не держи в iCloud: облако выгружает файлы с диска, и рендер зависает.

## Что внутри
- `.claude/skills/montazh-reels/SKILL.md` — правила монтажа для Claude. Скилл подхватывается сам, когда открываешь папку.
- `engine/` — движок:
  - нарезка и расшифровка (faster-whisper);
  - сборка композиции (HyperFrames + GSAP);
  - 3D-модули `arena3d.js` и `lico3d.js` (Three.js);
  - объёмный кириллический текст.
- `examples/` — два готовых ролика целиком, эталон приёмов.
- `references/` — правила моушн-дизайна.

## Требования
- macOS или Linux.
- Claude Code (подписка Pro или Max).
- Python 3.11 (`engine/compose.pyc` собран под 3.11).
- Node.js 22+.
- ffmpeg.

## Лицензии
- Шрифты Inter, Playfair Display и JetBrains Mono — OFL.
- Three.js — MIT.
- GSAP — стандартная лицензия GreenSock.
- Модели MediaPipe — Apache 2.0, скачиваются в `setup.sh`.
- Звуки — с Pixabay, скачиваются отдельно.
- Кадры из фильмов бери короткими фрагментами (1–3 с) из официальных клипов. Ответственность за чужие материалы на тебе.
