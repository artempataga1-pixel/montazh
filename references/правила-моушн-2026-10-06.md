## Главное правило
**Графика показывает РЕЗУЛЬТАТ в виде интерфейса, а не повторяет речь текстом.** Каждый пункт/факт ролика получает
свою мини-сцену-метафору: тумблер, датчик, документ с пометками, расписание, график, карточки со счётчиком,
чат-пузырь. Текст на экране — только ключ (код, число, 1–3 слова).

## Приёмы (брать в каждый ролик формата 2/5)
1. **Кадр 0 с — UI-уведомление поверх лица.** Карточка в стиле приложения (иконка ChatGPT/Claude, «сейчас») и в ней
   печатается заголовок-хук синхронно с голосом; ключевое слово выделяется как выделение мышью (андрей, 0–2 с).
2. **Пункт списка = номер-чип + поле ввода + результат.** Цветной квадрат с номером, рядом поле ввода, где печатается
   код/запрос (`/truth`), кнопка отправки; через 0,3 с под ним появляется сцена-результат. Цвет чипа меняется на
   каждом пункте (синий → зелёный → жёлтый…). В движке: `craft.item()` + `typing()` + `G()`.
3. **Сцена-метафора под каждый пункт** (не текстом!):
   - «отключает вежливость» → тумблер переключается;
   - «шанс / вероятность» → датчик-спидометр со стрелкой и процентом;
   - «находит, что спрятано» → документ, на котором загораются красные плашки;
   - «распорядок» → вертикальный календарь с цветными блоками;
   - «короче / без воды» → карточка ответа, у которой счётчик слов падает, капли «воды» отлетают;
   - «рост» → линия графика рисуется (SVG stroke) + большое «+10 000».
4. **Текст по дуге вокруг головы** (alice, 0,5–4 с): слова хука идут по кривой вдоль контура головы — заменяет
   обычные субтитры в хуке, работает как pattern interrupt.
5. **Графика на свободной стороне кадра.** Спикер смещается (камера `cam` со сдвигом), свободная половина — под
   список/карточки/график. Не перекрывать лицо.
6. **Карточки с анимированными числами** (просмотры «1,4 млн» → счётчик бежит) для любых цифр.
7. **Финал = макет действия зрителя.** Поле комментария со словом «КОДЫ» печатается + кнопка отправки — CTA
   визуально, а не только голосом (alice, 33 с).
8. **Аватар-мемоджи автора** в углу сцены на «личных» пунктах — оживляет UI-сцены без лица (андрей, 34–56 с).
9. **Полноэкранные UI-сцены без лица допустимы** на 3–8 с, если голос продолжает — лицо возвращается на поворотах.

## Принципы движения (из PDF эксперта)
- Перед кодом решить: финальная композиция, **главный (hero) элемент**, порядок появления, как входит каждый
  крупный элемент, где сцена заканчивается.
- **Никаких сплошных fade-in.** Карточки: slide/scale/rotate/stack; текст: по словам/буквам, маской, сдвигом;
  линии и обводки: рисование SVG-штрихом; интерфейс: ступенчато (stagger).
- Главное появляется раньше вспомогательного; фон движется тише переднего плана.
- Ничего лишнего «для сложности»: каждый элемент или из сценария, или нужен для смысла.
- 9:16, всё резкое на высоком разрешении, никаких кнопок плеера, скроллбаров, «браузерного» UI.

## Формат-идея (для Альфреда)
Сплит «Opus 5.5 / original» (alice ×31,6): одно и то же видео сверху смонтировано Claude, снизу исходник. Автор
голосом командует («смести меня вправо, слева напиши…») — графика появляется на команду. Наш провал «этот рилс
смонтировал ИИ» (01.10, 260) был без сплита и без голосовых команд → передано в журнал/дирижёру.

## Совместимость со старыми правилами
Остаются в силе: первый кадр — лицо + графика сразу; плавные переходы через размытие; печать синхронно со словами;
глитч-звук ≤ 0,03; светлая/тёмная тема по очереди; живое демо с телефона — только субтитры.

## Записи экрана автора (правка 07.10, IMG_9111)
- Показывать ЦЕЛИКОМ: от ввода до результата, ускорять под длину фразы (до ×4 — печать ещё читается); длиннее — срезать
  начало (выбор фото), а не результат. Хвост с Пунктом управления (последние ~0,9 с) — всегда вырезать.
- Тихие окончания слов («фо-то») чистка пауз (−28 дБ) срезает — после tighten проверять края кусков по −40 дБ.

## Безопасная зона сверху (правка автора 07.10, IMG_9199)
- Верх кадра (~0–250 px из 1920) в Reels закрыт интерфейсом Instagram (надпись «Reels», кнопки) — текст и анимацию
  туда НЕ ставить. Любая графика/плашка/уведомление начинается не выше ~260 px; в состоянии card зона графики — 260–840 px.
- Низ (~1650–1920) тоже под подписью и кнопками — субтитры и CTA не ниже ~1600 px.
