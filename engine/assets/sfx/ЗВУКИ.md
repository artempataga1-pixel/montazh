# Звуки эффектов

Звуки не входят в пакет: лицензия Pixabay запрещает раздавать их отдельными файлами.
Скачай бесплатные аналоги на https://pixabay.com/sound-effects/ (поиск по слову в скобках), сохрани в эту папку
**ровно с такими именами** (mp3) — движок ищет их по имени:

| файл | что искать на Pixabay | где звучит |
|---|---|---|
| whoosh-short.mp3 | short whoosh | переходы камеры, вставки |
| whoosh.mp3 | whoosh | появление 3D |
| whoosh-cinematic.mp3 | cinematic whoosh | большие входы сцен |
| pop.mp3 | ui pop | чипы, плашки |
| click.mp3, click-soft.mp3 | ui click / soft click | пункты, баллы |
| ping.mp3 | ping notification | акценты |
| chime.mp3 | chime | позитивный ответ |
| error.mp3 | error ui | «плохо», зачёркивание |
| notification.mp3 | phone notification | CTA, комментарий |
| typing.mp3, key-press.mp3 | keyboard typing | печать текста |
| glitch-1.mp3, glitch-2.mp3, glitch-3.mp3 | glitch | цифры, скан (очень тихо) |
| impact-bass-1.mp3, impact-bass-2.mp3 | bass impact / boom | удар заголовка |
| riser.mp3 | riser | нарастание перед итогом |
| sparkle.mp3 | sparkle / magic | победа, итог |
